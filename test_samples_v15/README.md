# v1.5 合成附件样本（可复现）

这些文件全部为工程内合成样本，不含用户隐私数据，用于验证本地解析与 Mock 端到端：

| 文件 | 内容 | 预期 |
|---|---|---|
| `timetable.png` | 900×600 纯白底、黑字课程表（Mon/Tue） | 图片解码、EXIF 方向、压缩后 data URL |
| `课表.txt` | UTF-8 中文两行（周一/周二课程） | 文本来源 `txt1-L1`，中文正常 |
| `通知.csv` | 含引号、字段内逗号与换行的 CSV | 状态机解析为 3 条记录，重新转义 |
| `会议通知.docx` | 最小 OOXML，含一段文字与 2 行表格 | 输出段落 + “时间 \| 2026-11-24 09:00” |
| `安排.xlsx` | 最小 OOXML，共享字符串、日期样式、一个工作表“安排” | 日期序列换算、`[A2]` 地址、工作表名 |
| `会议通知.pdf` | 手工生成的最小文本 PDF（Helvetica，一行英文+日期） | PDFBox 提取文本，`pdf1-p1` 来源 |

生成方式见本轮实施记录；单元测试 `AiLocalParsersTest` 使用同一结构在临时目录重新生成并跑真实解析。
PDF 加密、坏文件、超大流、ZIP 条目超限等反例在测试中构造，不随样本包分发。

多页/超长/加密/扫描 PDF 与坏文件、ZIP 超限、图片 EXIF 等反例由 `AiLocalParsersTest` 在临时目录即时生成，不随包分发；
`AiV14RegressionTest` 还会生成两页 PDF 验证续聊选页范围。
